# CRM System - Frontend

Frontend частина для системи управління клієнтами та угодами.

## Технології

- **Next.js 16** - React фреймворк
- **TypeScript** - типізація
- **shadcn/ui** - UI компоненти
- **Tailwind CSS** - стилізація
- **SWR** - кешування та синхронізація даних
- **React Hook Form** - управління формами
- **Zod** - валідація форм
- **Axios** - HTTP клієнт

## Функціональність

### Клієнти
- ✅ Створення клієнта
- ✅ Перегляд списку клієнтів з пагінацією
- ✅ Перегляд деталей клієнта з його угодами
- ✅ Редагування клієнта
- ✅ Видалення клієнта (каскадно видаляються його угоди)

### Угоди
- ✅ Створення угоди
- ✅ Перегляд списку угод з пагінацією та фільтрацією (статус, клієнт)
- ✅ Редагування угоди
- ✅ Видалення угоди

## Встановлення та запуск

1. Встановіть залежності:
```bash
npm install
```

2. Створіть файл `.env.local` (опційно, якщо бекенд на іншому порту):
```env
NEXT_PUBLIC_API_URL=http://localhost:3000
```

3. Запустіть dev сервер:
```bash
npm run dev
```

4. Відкрийте [http://localhost:3001](http://localhost:3001) у браузері (фронтенд запускається на порту 3001, бекенд - на порту 3000)

## API Endpoints

Фронтенд використовує бекенд API:

### Клієнти
- `POST /clients` - створити клієнта
- `GET /clients?page=1&limit=10` - список клієнтів
- `GET /clients/:id` - отримати клієнта
- `PATCH /clients/:id` - оновити клієнта
- `DELETE /clients/:id` - видалити клієнта

### Угоди
- `POST /deals` - створити угоду
- `GET /deals?page=1&limit=10&status=NEW&clientId=uuid` - список угод
- `GET /deals/:id` - отримати угоду
- `PATCH /deals/:id` - оновити угоду
- `DELETE /deals/:id` - видалити угоду
